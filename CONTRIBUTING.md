# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

- Open an issue to report a bug, suggest an enhancement, or discuss a proposed change.
- For code or documentation changes, create a focused pull request with a clear description of what changed and why.
- Keep changes consistent with the project's purpose and existing style.
- Test the simple-interest script with representative principal, rate, and time values before submitting a change.
- Be respectful and follow the project's [Code of Conduct](./CODE_OF_CONDUCT.md).
