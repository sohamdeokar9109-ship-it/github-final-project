# Simple Interest Calculator

A small Bash command-line program that calculates simple interest from a principal amount, an interest rate, and a time period.

## Usage

Run the script from a terminal:

```bash
bash simple-interest.sh
```

Enter the principal, rate of interest (as a percentage), and time period when prompted. The script displays the simple interest using:

```text
SI = (Principal × Rate × Time) / 100
```

The rate and time period should use consistent units (for example, an annual rate with time measured in years).
