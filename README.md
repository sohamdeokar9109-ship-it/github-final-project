# Paradise Nursery

Paradise Nursery is a responsive plant-shopping application built with React, React Router, and Redux Toolkit. Browse houseplants across three collections, add plants to your cart, and adjust quantities before checkout.

## Run locally

1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev`.
3. Open the local URL printed by Vite.

Use the navigation to explore the home page, plant collections, and shopping cart. Checkout currently displays a "Coming Soon" message.
